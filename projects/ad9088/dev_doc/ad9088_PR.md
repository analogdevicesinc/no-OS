Title: ad9088: add AD9088 (Apollo) MxFE driver and VCU118 project

---

## Pull Request Description
Add support for the AD9088 (Apollo) MxFE: the no-OS driver, the vendor Apollo API tree it is built on, and a project for the AD9084-EVAL board on VCU118 with two examples.

Seven commits, ordered so the dependencies land first. The first five are shared infrastructure the driver needs; the last two are the driver and the project.


#### Changes:
- cmake: add firmware blob embedding supp
  Link a vendor .bin image into the ELF with objcopy -I binary rather than converting it to a C array first. Staging plus WORKING_DIRECTORY makes the caller's SYMBOL_PATH the whole of the binary* symbol name, independent of where the image sits on disk.
- util: no_os_crc32: add CRC-32 support
  Fourth CRC width alongside the existing CRC-8/16/24, following the same table-generation pattern and pulled  into the aggregate no_os_crc.h.
- drivers: frequency: adf4030: add JESD204 support
  The ADF4030 generates BSYNC and SYSREF, so it takes part in JESD204 bring-up rather than being configured once at probe. Register it as a JESD204 device and realign the channels that ask for it on CLK_SYNC_STAGE4, driven by an optional init-time channel list. Carries the supporting fixes that alignment needs to converge (TDC_SOURCE, MATH_BUSY, per-operation poll timeout, AVGEXP mask).                                            drivers: frequency: adf4382: add phase
  Detect legacy silicon and apply the matching defaults, convert the phase API from picoseconds to femtoseconds so sub-picosecond BSYNC delays can be expressed, and give adf4382_pfd_compute() a PFD range check across all nine call sites.
- include: jesd204: add AD9088 FSM stages
  Two optional setup stages before link enable, and post-setup stages where multi-chip sync calibration runs once the link is up. Existing drivers leave the new op slots NULL and are unaffected.                         
- drivers: rf-transceiver: ad9088: add driver
  The driver, the vendor Apollo API tree it is built on, and the firmware images.
- projects: ad9088: add VCU118 project
  basic_example brings up the JESD204C links and reports link status. dma_example additionally loads the TX DMA from a sine LUT and reads the result back through the RX DMA; it assumes external loopback cables are fitted.

#### Testing
Vitis 2025.1, MicroBlaze, AD9084-EVAL on VCU118.

- Both examples build clean from scratch with the SDT ABI active; astyle passes over every file CI checks; sphinx-html builds and both new README.rst render through their stubs.
- JESD204C links reach LINK_RUNNING, full FSM including the new optional-setup and post-setup stages.
- Subclass 1: ADF4030 as SYSREF provider, SYSREF Phase Locked and SYSREF captured on both AXI cores.
- Multi-chip sync calibration passes init-cal validation.
