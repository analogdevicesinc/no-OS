## Pull Request Description

`util/` provides CRC-8, CRC-16 and CRC-24 helpers but no 32-bit variant. Add
one.

`no_os_crc32_be()` computes the big-endian Ethernet AUTODIN II CRC-32 — MSB
first, no input or output bit reflection, no final XOR, so both the seed and
the result are raw and a computation can be continued incrementally by passing
the previous return value back in. The header joins the aggregate
`no_os_crc.h`, so users of that header pick it up without another include.

It is computed bitwise rather than from a lookup table, unlike the narrower
widths. Those are called repeatedly on short frames, where a 256-entry table
pays for itself; a checksum taken once over a large buffer does not benefit
from one, and the shift-based form is smaller and easier to check against a
reference.

**Series** — each of these applies to `main` on its own; only the last is stacked:

1. FCE-1057-ad9088-api - ad9084/ad9088 vendor Apollo API
2. FCE-1054-cmake-firmware-blob - firmware blob embedding
3. **this PR** - no_os_crc32
4. FCE-1056-adf4030-jesd204 - adf4030 JESD204 support
5. FCE-1059-adf4382-phase - adf4382 phase alignment
6. FCE-112-add-ad9088-support - ad9084/ad9088 driver + VCU118 project (needs 1-5)

#### Testing

validates the profile the driver loads on AD9084-EVAL on VCU118.
